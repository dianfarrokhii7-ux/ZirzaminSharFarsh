# زیرزمین شهر فرش

بازی ترسناک سه‌بعدی فارسی، تک‌نفره و چندنفره (۱ تا ۴ نفر).

## اجرا روی کامپیوتر
    npm install
    npm start
سپس http://localhost:3000 را باز کنید.

## انتشار روی Render
Web Service بسازید؛ Build: `npm install` و Start: `npm start`.
(فایل render.yaml هم برای ساخت خودکار آماده است.)

## فصل‌ها
۰ پیش‌درآمد • ۱ انبار فرش‌های ممنوعه • ۲ راهروی بی‌پایان • ۳ آزمایشگاه اکسیر جوانی
**Nightmare Expansion**
- ۴: اتاق ۱۰۰ ریالی — پرونده، عکس‌ها، رمز گاوصندوق (گاوصندوق فقط بعد از پیدا کردن رمز باز می‌شود)
- ۵: رامبد جوان — سه کارت دسترسی ← برق ← در امنیتی ← اتاق کنترل. رامبد صدای دویدن را می‌شنود، با دیدن بازیکن تعقیب می‌کند و در تعقیب درها را می‌بندد.
- ۶: طبقه دوم متروکه — چهار فیوز (فیوز آخر نزدیک در مخفی است) ← برق ← در مخفی ← راه‌پلهٔ طبقه سوم.
پایان هر فصل (۳ تا ۶) یک کات‌سین دارد و بعد از فصل ۶ «ادامه دارد...» نمایش داده می‌شود.
