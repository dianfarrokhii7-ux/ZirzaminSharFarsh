# زیرزمین شهر فرش

بازی ترسناک سه‌بعدی فارسی، تک‌نفره و چندنفره (۱ تا ۴ نفر).

## اجرا روی کامپیوتر
    npm install
    npm start
سپس http://localhost:3000 را باز کنید.

## انتشار روی Render
Web Service بسازید؛ Build: `npm install` و Start: `npm start`.
(فایل render.yaml هم برای ساخت خودکار آماده است.)
