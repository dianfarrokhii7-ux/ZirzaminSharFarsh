# زیرزمین شهر فرش

بازی ترسناک سه‌بعدی فارسی، تک‌نفره و چندنفره (۱ تا ۴ نفر).

## اجرا روی کامپیوتر
    npm install
    npm start
سپس http://localhost:3000 را باز کنید.

## انتشار روی Render
Web Service بسازید؛ Build: `npm install` و Start: `npm start`.
(فایل render.yaml هم برای ساخت خودکار آماده است.)

## فصل‌ها
۰ پیش‌درآمد • ۱ انبار فرش‌های ممنوعه • ۲ راهروی بی‌پایان • ۳ آزمایشگاه اکسیر جوانی
**Nightmare Expansion**
- ۴: اتاق ۱۰۰ ریالی — پرونده، عکس‌ها، رمز گاوصندوق (گاوصندوق فقط بعد از پیدا کردن رمز باز می‌شود)
- ۵: رامبد جوان — سه کارت دسترسی ← برق ← در امنیتی ← اتاق کنترل. رامبد صدای دویدن را می‌شنود، با دیدن بازیکن تعقیب می‌کند و در تعقیب درها را می‌بندد.
- ۶: طبقه دوم متروکه — چهار فیوز (فیوز آخر نزدیک در مخفی است) ← برق ← در مخفی ← راه‌پلهٔ طبقه سوم.
- ۷: طبقه سوم — THE FORGOTTEN FLOOR — برق ← سه کارت ← دوربین‌ها ← اتاق نگهبانی ← رمز آزمایشگاه مخفی. رویدادها: راه‌پله و نوشته‌های دیوار، فرش متحرک، دوربین‌ها، تلفن پژمان، آسانسور خراب.
- ۸: پروژه R — THE REAL EXPERIMENT — چهار پرونده ← خاموش کردن دستگاه اصلی (آژیر + تعقیب بزرگ) ← رمز اتاق کنترل ← غیرفعال کردن سیستم امنیتی ← اتاق اصلی پروژه R.
پایان هر فصل (۳ تا ۸) یک کات‌سین دارد و بعد از فصل ۸ «ادامه دارد!» نمایش داده می‌شود.

## سیستم ترس حرفه‌ای (همهٔ فصل‌ها)
- **جامپ‌اسکیر پویا:** مدیر ترس برای هر بازیکن، رویدادها را تصادفی و بدون تکرار پشت‌سرهم انتخاب می‌کند؛ قبل از هر جامپ‌اسکیر سکوت می‌شود و بعد صداها آرام‌آرام برمی‌گردند. رویدادهای وابسته به موقعیت: ایستادن طولانی، رفتن به بن‌بست، نزدیک شدن به آیتم، برگشتن به جای قبلی (محیط عوض شده).
- **صدای سه‌بعدی (HRTF):** قدم‌های رامبد از جهت واقعی او، نفس‌ها، فرش، درهای فلزی، دستگاه‌های دور، سکوت ناگهانی.
- **هوش مصنوعی رامبد:** گشت بین چهارراه‌ها، شنیدن دویدن و بررسی محل صدا، تعقیب با سرعت فزاینده، جست‌وجوی مسیرهای دیگر بعد از گم کردن بازیکن، ظاهر شدن در دوردست، و در فصل‌های ۷ و ۸ کمین ناگهانی.
- **موسیقی پویا:** اکتشاف (آرام)، نزدیک شدن (تنش‌زا)، تعقیب (ضرباهنگ سریع)، سکوت قبل از جامپ‌اسکیر.
- **افزایش تدریجی ترس:** شدت هر فصل در جدول `INT` (در game.js) تعیین می‌شود.
